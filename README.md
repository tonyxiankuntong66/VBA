 # 🚀 CalcUnits.bas（Excel 智能量纲计算函数）
## ✨ 核心特性
- ⚡ **特性 1**：这里写最吸引人的功能点。
- 🛡️ **特性 2**：例如工业级的防错和容错机制。
- 🔄 **特性 3**：自动化、智能化的操作体验。

## 🛠️ 安装与部署
1. 第一步：克隆或者下载本仓库代码。
2. 第二步：打开 Excel 的 VBA 编辑器（Alt + F11）。
3. 第三步：导入 `.bas` 模块文件。

## 📊 使用示例
in excel cell：
=CALC_UNITS("2.5 mg/mL", "*", "4 mL")  => 输出结果: 10 mg
支持单元格引用和公式套用。
